# SaaS CRM MVP — 畫面資訊架構（IA）

- **日期**：2026-09-12
- **範圍**：MVP（平台 / CRM / 服務台 / 排程 / 極簡報表）
- **原則**：租戶內導航；所有列表預設帶租戶資料；權限不足顯示空態而非報錯頁

---

## 1. 全域殼層

```
[Logo / 產品名]  [租戶名稱]
導航：
  首頁（摘要）
  客戶（公司 / 聯絡人）
  商機
  工單
  排程
  報表
  設定（admin）
右側：搜尋（MVP 可先全域客戶+工單） / 通知（可先佔位） / 頭像選單
```

- 未加入任何租戶 → 引導建立或接受邀請  
- 多租戶成員 → 頭像選單可「切換租戶」（僅限自己的 memberships）

## 2. 頁面地圖

### 2.1 首頁 `/`
- 卡片：未結工單數、本週排程、商機漏斗摘要、今日待辦活動  
- 快捷：新建商機 / 新建工單 / 新建排程

### 2.2 客戶
| 路由 | 說明 |
|------|------|
| `/companies` | 公司列表：搜尋、標籤、負責人篩選 |
| `/companies/new` | 新建 |
| `/companies/:id` | 詳情：概要、聯絡人、商機、相關工單、標籤 |
| `/contacts` | 聯絡人列表 |
| `/contacts/new` | 新建（可預填 company） |
| `/contacts/:id` | 詳情：欄位、相關商機／工單、活動 |

### 2.3 商機
| 路由 | 說明 |
|------|------|
| `/opportunities` | 列表 **或** 看板（階段欄）；篩選負責人／階段 |
| `/opportunities/new` | 新建 |
| `/opportunities/:id` | 詳情：階段操作、金額、活動時間線、關聯客戶 |

**階段操作**：詳情頁主按鈕「推進／標記成交／失單」；非法轉換 disable + tooltip。

### 2.4 工單
| 路由 | 說明 |
|------|------|
| `/tickets` | 列表：狀態、優先級、指派人；工程預設「未指派+我的」 |
| `/tickets/new` | 新建（可選公司／聯絡人／商機） |
| `/tickets/:id` | 詳情：狀態流、指派、描述、留言（公開／內部切換）、關聯排程面板 |

**關聯排程面板**：搜尋既有排程 → 連結；或「新建排程並連結」；可解除連結。

### 2.5 排程
| 路由 | 說明 |
|------|------|
| `/schedules` | **日曆**（週預設）+ 列表切換；篩選人員 |
| `/schedules/new` | 新建（出勤／booking）；時間衝突 → toast/`warnings`，仍可存 |
| `/schedules/:id` | 詳情：狀態、完成備註／取消原因、關聯工單 |

### 2.6 報表 `/reports`
- 三塊：商機各階段數量、工單開關／未結、本週排程／完成  
- MVP 無自訂報表、無匯出（可後補 CSV）

### 2.7 設定（admin）`/settings`
- 公司／時區／工作日  
- 成員與邀請、角色變更  
- （佔位）方案資訊

### 2.8 Auth
- `/login` `/register`  
- `/invites/:token` 接受邀請

## 3. 關鍵元件（跨頁）

- **DataTable**：排序、分頁、篩選 chips  
- **StatusBadge** + **TransitionMenu**（吃 shared enum）  
- **EntityPicker**：公司／聯絡人／成員／排程／工單  
- **ActivityTimeline**（商機／聯絡人）  
- **CommentThread**（`is_internal` 視覺區隔）  
- **Calendar** + 事件色依 `type` / `status`  
- **EmptyState** / **NoPermission** / **ConflictWarning**

---

## 4. UX 規則（MVP）

| 情境 | 行為 |
|------|------|
| 無權限路由 | 導向首頁 + toast「沒有權限」 |
| 列表無資料 | EmptyState + 主 CTA（新建） |
| 排程時間衝突 | 黃色警告，不擋儲存 |
| 刪除 | 公司／聯絡人：確認；工單／排程：優先「關閉／取消」 |
| 內部備註 | 明顯標「僅內部」；業務角色若不開放則不顯示切換 |
| 鬆耦合 | 工單完成不自動完成排程；UI 不暗示自動連動 |
